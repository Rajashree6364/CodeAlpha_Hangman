# 🎮 CodeAlpha Hangman Game

## 📌 Project Overview

This project is a simple text-based Hangman Game developed using Python as part of the CodeAlpha Python Programming Internship.

The player has to guess a randomly selected word one letter at a time.

## 🎯 Features

- Random word selection
- Five predefined words
- Letter-by-letter guessing
- Maximum of six incorrect guesses
- Input validation
- Duplicate guess detection
- Win and lose conditions
- Console-based interface

## 🛠️ Technologies Used

- Python
- Random module
- Lists
- Strings
- Loops
- Conditional statements

## ▶️ How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

```bash
python hangman_game.py
